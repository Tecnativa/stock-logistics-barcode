The lots created from the lot names read on the capture screens
(``stock_capture``), e.g. a GS1-128 barcode of a receipt, get the
expiration date (AI 17) and the best before date (AI 15) read with them.
When only the best before date is read, the expiration date is computed
with the times of the product, and Odoo computes the removal and alert
dates.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_
